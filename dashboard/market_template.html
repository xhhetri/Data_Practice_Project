How to use this outlook

  1. Use the outlook as a monthly sales planning reference alongside current observations.
  2. Check the source cutoff and interval width before quoting a forecast.
  3. Compare both the selected model and seasonal-naive errors; a model can lose on new periods.
  4. Investigate unusual changes using source evidence. The model does not establish a shortage or a policy effect.
